# Run Thor Agent with Nous Portal (removed)

This guide is retired. Nous Portal has been removed from Thor Agent, so there is no Portal subscription to sign up for and no `thor setup --portal` step anymore.

Use one of these instead:

- **[ThorHub](../integrations/thorhub.md)** — buy token packages at https://llm.thormarket.site/beli, get a sub-key, and add it to Thor as a custom provider (`base_url https://llm.thormarket.site/v1`). Check your balance with `/topup` or `/skill saldo`.
- **Direct providers** — run `thor setup` and choose your own provider and model. ThorHub is one optional provider; you are free to pick any other.
